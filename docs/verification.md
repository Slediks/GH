Во время сценария не обнаружено HTTP-запросов на внешние hostname.
В реальном запросе iframe отсутствует Cookie; попытка открыть файл без ticket
через браузер получает 403. Проверены оба размера экрана.

## Нагрузка

Запуск `python scripts/load_test.py --clients 100 --seconds 30`.
Измерение начинается после подключения всех клиентов, в live-фазе с достаточным
остатком времени. Setup и disconnect не включаются в интервал. Все клиенты получают
реальный поток от отдельного серверного симулятора, а не искусственные сообщения.

| Метрика | Результат |
|---|---|
| Одновременно подключено | **100 / 100** |
| Интервал | **30 с** |
| Всего снимков | **30 014** |
| Минимум на клиента | **299** |
| Медиана доставки | **48,10 мс** |
| p95 доставки | **71,21 мс** |
| Различия состояния для одинакового match_id/sequence | **0** |

Исходные измерения: [load-results.json](load-results.json).
Первый диагностический прогон включал этапы подключения и проходил одновременно
со сборкой: p95 был около 9,7 с. После выделения стабильного измерительного интервала
без параллельной сборки получены значения выше. Это тест localhost, не измерение
Wi-Fi или 100 реальных браузеров с Canvas. На целевом сервере тест нужно повторить.

## Честные ограничения и незавершённые интеграции

- **Не предоставлен контракт существующего API авторизации.** Конфигурируемый JSON
  адаптер и mock работают независимо; production-вход требует реальных URL, полей,
  идентификатора, заголовков и контрактной проверки с владельцем API.
- Для текущего предпросмотра явно включён development mock. Он предназначен для
  локальной проверки, а не production. В БД стенда есть тестовые профили.
- Футбольная физика, вратарь и тактики упрощены. Пенальти моделируют точность и сейв
  вероятностно, а результат каждого удара визуализируется. ML и заранее выбранного
  победителя матча нет. Полный replay не реализован согласно границам первой версии.
- Оценка коэффициентов из 32 зеркальных прогонов шумная. Это рабочая оценка,
  не гарантия точных вероятностей или устойчивой экономики без суточного лимита.
- Браузерная активность не защищает абсолютно от автоматизации/вредоносного HTML.
  Браузер sandbox и CSP проверены в Chromium; Safari/Firefox отдельно не проверялись.
- Теги хранятся как ограниченный JSON-массив в игре; отдельного справочника tags нет.
- Снимки Canvas интерполируются через requestAnimationFrame; отдельного исследования
  стабильных 60 FPS на разнообразных устройствах не проводилось.
- HTTPS, локальный DNS и доверенные сертификаты реального сервера на этом стенде
  не настраивались. Два hostname обязательны для изоляции cookies.
- Процедура резервного копирования и восстановления описана; аварийное восстановление
  целого сервера из архива пока не было предметом отдельного сквозного прогона.
- Для сквозного offline-проверочного сценария контролировались внешние запросы;
  физическое отключение сетевого интерфейса отдельного production-сервера не выполнялось.

## Повторение

Команды — в README. PostgreSQL-тесты очищают только явно заданную БД с суффиксом
`_test`. Playwright требует development mock, три демоигры и доступность отдельного
game-origin. Не запускайте нагрузочные mock-логины на production.
