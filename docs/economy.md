# Очки, активность и ставки

Единица хранения — 1/100 очка, integer. 100 стартовых очков = 10000 в БД.
Все API суммы также в сотых. Умножение выплаты целочисленное:
`amount * odds // 100`; коэффициент 1,90 хранится как 190. Ни float, ни клиентские
расчёты не изменяют кошелёк. Незавершённые ставки вычитаются сразу.

Кошелёк нельзя сделать отрицательным: проверка под row lock и CHECK constraint.
Журнал append-only: welcome, activity, bet, payout, refund, adjustment. Для каждого
ключа операции допускается одна запись. Повторная доставка уже принятой ставки
с теми же параметрами возвращает её ID; другие параметры дают 409.

В одной транзакции ставки блокируется матч, проверяется `betting_open` и серверный
дедлайн, фиксируется ставка, блокируется кошелёк, списывается сумма, пишется журнал.
UNIQUE(user_id,match_id) дополняет сериализацию. Выплата и возврат используют один
ключ `settle:<bet_id>`; завершённый расчёт не выполняется повторно.

Отмена возвращает исходную ставку. Проигрыш — нулевая выплата. Чистый результат
выигрыша = выплата − ставка. Возврат даёт 0, но исключается из рейтинга результатов.
Начисления за активность не зависят от побед/поражений. Переводов между пользователями нет.

## Аренда активности

Новый запуск атомарно записывает `wallet.active_session`. Старый heartbeat не может
забрать аренду обратно. Это действует между вкладками и устройствами. Сервер
получает только sequence, eligible и input_seen. Sequence исключает повторную доставку.

Клиент считает eligible при видимой вкладке, фокусе окна и клике/клавише/касании за
последние 120 секунд. Mousemove не учитывается. События из игры проходят проверку
источника и ID. На футболе кнопка «Я смотрю» — обычный сигнал ввода.

Первый heartbeat только начинает интервал. Последующие приходят каждые 15 секунд.
Сервер считает фактически прошедшее время, принимает непрерывные интервалы от 1 до
20 секунд при действующей аренде (35 с) и подтверждённой активности. Пропущенный
интервал не компенсируется. Потеря фокуса/видимости отправляет остановку, обнуляет
аренду. Остаток менее минуты хранится в кошельке и переживает смену сессии/перезапуск.
Целые секунды округляются вниз; дробные доли отдельного heartbeat не начисляются.

После 60 подтверждённых секунд — 1 очко. Настройки доступны администратору;
внутренние интервалы heartbeat и idle не выводятся как редактируемые поля, чтобы
не рассинхронизировать клиентскую проверку.

## Эмиссия

Суточного лимита нет. Админпанель показывает суммарные welcome/activity, списания
bet, payout, refund и adjustment. Это наблюдаемость, а не гарантия устойчивости
экономики. Корректировка требует причины и request_id. Повторная отправка с тем же
request_id не изменяет баланс повторно. Журнал администратора также неизменяемый.
